# Calculator Konversi Satuan

## Deskripsi

Kalkulator Konversi Satuan adalah aplikasi yang digunakan untuk membantu pengguna melakukan konversi berbagai macam satuan dengan mudah dan cepat. Pengguna dapat memasukkan nilai, memilih satuan awal dan satuan tujuan, kemudian aplikasi akan menampilkan hasil konversinya.

## Tujuan

Project ini dibuat untuk menerapkan penggunaan HTML, CSS, JavaScript, dan Tailwind CSS dalam membuat aplikasi web yang dapat melakukan konversi satuan serta menyimpan dan menampilkan riwayat konversi.

## Fitur

### Calculator

Digunakan untuk melakukan operasi matematika seperti:

* Penjumlahan (+)
* Pengurangan (-)
* Perkalian (×)
* Pembagian (÷)
* Sin Cos Tan
* Menghapus angka atau perhitungan
* Menampilkan hasil perhitungan

### History

Menampilkan riwayat konversi yang telah dilakukan oleh pengguna. Dengan fitur ini, pengguna dapat melihat kembali hasil konversi sebelumnya.

### Header

Bagian atas aplikasi yang menampilkan nama atau judul aplikasi serta membantu pengguna mengenali halaman yang sedang digunakan.

## Bahasa Pemrograman yang Digunakan
